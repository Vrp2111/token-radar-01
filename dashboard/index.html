Token Radar

Every protocol that records no token yet, ranked by what its launch would be worth — and the exact steps to farm each one before it happens.

“Records no token” is what the data says, never proof a protocol has none. Implied values are this radar's own claim, computed from the snapshot's figures — not a prediction that a token will launch, or when.

How the ranking works

implied = TVL × category multiple × growth × maturity × momentum

The category multiple is the median market-cap-to-TVL ratio of the protocols in that category whose token already trades — computed from this snapshot, so the market sets the price of each kind of TVL. Growth is the protocol's 7-day TVL change (clamped −50%…+300%), maturity grows with how long it has run with no token, and a protocol growing 25% or more in a week earns a momentum bonus. No name is ever special-cased: the same formula scores all 289 rows.
